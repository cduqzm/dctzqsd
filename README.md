# dctzqsd

A Brave/Chrome extension that restyles the Summa College Eduarte student portal in a minimal dark design.

[![Download dctzqsd](https://img.shields.io/badge/Download-dctzqsd.zip-2ea44f?style=for-the-badge&logo=github)](https://github.com/cduqzm/dctzqsd/releases/latest/download/dctzqsd.zip)

## Install

1. Click **Download** above and unzip the file.
2. Open `brave://extensions` (or `chrome://extensions`) and enable **Developer mode**.
3. Click **Load unpacked** and select the unzipped `dctzqsd` folder.
